# Borja — curated case study (Spanish)

This folder demonstrates **how** a real voice guide can be derived from original writing, explicit feedback, and coedited article versions.

- [`corpus.md`](corpus.md): selected excerpts and their provenance.
- [`editorial-decisions.md`](editorial-decisions.md): what each example teaches; proposals marked as proposals.
- [`VOICE.md`](VOICE.md): working rules inferred from the evidence.
- [Editing prompt](../../prompts/edit.md): use the voice guide on an existing draft.

**Important:** This is a curated sample, not a complete archive of chats or all of Borja's writing. It does not imply that all edits were approved or published. The longer internal guide contained 28 cases, but **28 does not mean 28 validated before/after pairs**.

All source examples are in Spanish. The overall framework is language-agnostic.

See also [a worked editorial walkthrough](before-after.md) and [the A/B demonstration](../../DEMO.md).
