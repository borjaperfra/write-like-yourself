# Try it: generic prompting vs. your voice guide

This is a **small personal evaluation**, not a scientific benchmark.

## Setup
- Choose three real tasks you might publish: one short post, one 300–500-word article section, and one practical email.
- Keep the same model, task brief, input facts and length constraints across conditions.
- A: Generic prompt (“write clearly, naturally and professionally”).
- B: The same brief plus your `VOICE.md` and approved evidence examples.
- Run both conditions separately without sharing previous outputs.
- Shuffle/hide which condition produced each text before scoring, where possible.

## Scoring (1–5)
| Criterion | Question |
| --- | --- |
| Naturalness | Does it read like something the author could reasonably say? |
| Voice fidelity | Does it preserve distinctive judgment without copying mannerisms? |
| Specificity | Are examples, mechanisms and consequences concrete? |
| Rhythm | Does sentence and paragraph variation fit the format? |
| Accuracy | Are factual claims supported and uncertainty preserved? |
| Edit effort | How many substantive changes would the author need? (fewer is better) |

## Interpret carefully
Three tasks will not establish universal model behavior. Report honest preferences, surprising failures and limitations. Do not claim improvements you haven't tested.
