# Evaluating a voice guide responsibly

To test an improvement claim, use the same model and factual brief for both conditions. Give generic tone instructions in A and the voice guide in B; generate independently, with no cross-contamination of previous output. Blind the author to which is which, then rate fidelity, clarity, accuracy, rhythm and edit effort.

Record model/version, settings where known, exact prompts, brief, author preference and unresolved limitations.

If pairs were written or curated intentionally to demonstrate a point, label them **illustrative**, not a blinded experiment. A guided example is not evidence of measured performance. Prefer reporting what the author actually found, including when the guided version underperforms.

See root `EVALUATION.md` for a reusable scoring table.
